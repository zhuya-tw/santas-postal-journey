# 私人收藏室｜Google Forms、Sheets 與 Drive

私人收藏以你選定的 Google 帳號建立。在同一個受限 Drive 資料夾管理表單、試算表和掃描檔。公開圖鑑可獨立使用。

## 建立收藏室

1. 在 Google Drive 建立「Santa’s Postal Journey 私人收藏」，一般存取權保持為「受限」。在資料夾內建立「信件掃描」，再按年份分資料夾。
2. 建立 Google 表單「新增聖誕郵件收藏」。欄位可依下表建立。按「設定」，關閉結果摘要及收集電子郵件。保留多次提交，方便每年累積紀錄。
3. 在「回覆」分頁連結新試算表，再把試算表移到受限資料夾。保持回覆工作表原始欄位，並另建「收藏檢視」工作表做篩選與排序。
4. 需要讓家人填寫時，在表單的發布管理中把一般存取權設為「受限」，將指定帳號加為「填答者」。逐一檢查試算表、資料夾及掃描檔的一般存取權。由收藏者保管回覆表和掃描檔。個人使用可直接以擁有者帳號填寫。
5. 登出或使用無痕視窗開填答、試算表和掃描檔網址，確認需要授權。再以受邀帳號驗證只可填寫的範圍，最後用虛構資料試填，確認回覆正確進表。[Google 表單發布與填答權限](https://support.google.com/docs/answer/2839588)

| 欄位 | 類型與範例 |
| --- | --- |
| 收藏編號 | 必填短答，如 S2026-001，由你編號 |
| 郵局 | 必填短答，如 加拿大北極聖誕老人郵局 |
| 寄出日 | 日期，可留空 |
| 收到回信日 | 日期，可留空 |
| 收藏類型 | 單選，寄出信件／回信／郵戳／其他 |
| 掃描檔名 | 選填短答，如 S2026-001-back.jpg |
| 筆記 | 選填段落 |

掃描檔先上傳至私人 Drive，以收藏編號對應試算表，在私人試算表內需要時加入受限檔案的連結。請把私人表單網址、共用權限、信件掃描、住址、寄件者及回信資料留在 Google 收藏室。若想展示郵戳，先製作獨立的公開副本，移除信封正反面及圖片中可辨識的人名、地址、條碼與位置資訊，再決定是否對外分享。

## 備份及還原

- 例行備份時，下載回覆試算表的 XLSX 和原始回覆 CSV，並下載信件掃描資料夾。記錄備份日期、總筆數和掃描檔數量。表單問題與設定可用表單副本存到受限資料夾，另存欄位與分享設定記錄便於重建。
- 備份放在你控制的非公開儲存位置，含個人信件的離線副本應加密。每年抽查一筆收藏能從表格找到正確掃描檔。
- 還原時，先在受限資料夾上傳備份檔，從試算表打開歷史資料，再從表單副本或欄位表重建表單並連結新的回覆工作表。歷史資料留存獨立工作表，驗證筆數與掃描檔，再用虛構資料測試新一次提交。
- 若發現連結外洩，撤銷共用存取並檢查上層資料夾繼承。如誤推到公開 GitHub，須同時處理 Git 歷史與既有副本，並依暴露內容採取必要措施。
